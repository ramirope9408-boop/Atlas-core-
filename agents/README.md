# Agentes de IA
## Descripción

Los agentes son los empleados virtuales de ATLAS.

Cada uno tendrá una única responsabilidad.

## Agentes iniciales

- ATLAS CEO

- Trend Hunter

- Script Writer

- Voice Creator

- Video Creator

- Thumbnail Creator

- Publisher

- Analytics

- Growth

Cada agente podrá comunicarse con otros mediante el sistema de tareas.
