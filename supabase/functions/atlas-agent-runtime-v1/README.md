# ATLAS Agent Runtime V1

Experimental runtime. Not production routed.

## Layers
1. Company profile: identity, tone, policies, permissions.
2. Context manager: current opportunity, recent local turns, allowlisted CRM facts.
3. Relationship judgment: observable communication signals and action posture.
4. Planner: multi-operation AgentPlan.
5. Canonical tools: narrow tenant-scoped actions.
6. Validator/executor: ATLAS remains authority.
7. Response composer: natural reply grounded in tool results.
8. Activity ledger: every executed action becomes traceable in ATLAS.

## Non-negotiable
No unbounded transcript memory. Prior opportunities are retrieved only when explicitly relevant.
NO_ACTION is a first-class outcome.
Current/external facts require a live source/tool.
Follow-up is opportunity-aware and frequency/policy constrained.
Voice, WhatsApp and future channels share the same opportunity and activity model.
