# Backend de ATLAS
## Descripción

El Backend es el corazón de la plataforma.

Su responsabilidad es coordinar todos los servicios internos de ATLAS.

## Funciones

- Gestión de usuarios.

- Autenticación.

- Comunicación con la IA.

- API principal.

- Gestión de proyectos.

- Gestión de agentes.

- Gestión de automatizaciones.

- Sistema de tareas.

- Seguridad.

## Tecnologías

- Python

- FastAPI

- Docker

- PostgreSQL

- Redis
